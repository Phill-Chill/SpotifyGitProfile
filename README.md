## Créditos

Este projeto foi inspirado no trabalho do meu amigo [@guxvr](https://github.com/guxvr),
que criou o [rocket_league_readme_stats](https://github.com/guxvr/rocket_league_readme_stats) —
um card dinâmico de estatísticas do Rocket League para perfis GitHub.

A ideia e arquitetura (GitHub Actions + SVG gerado por Python) são baseadas no projeto dele.
